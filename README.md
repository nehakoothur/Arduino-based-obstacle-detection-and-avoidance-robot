# Obstacle Detection and Avoidance Robot

##  Project Description

This project is an Arduino-based obstacle detection and avoidance robot designed to detect obstacles in its path and automatically change direction to avoid collisions.

An ultrasonic sensor is used to measure the distance between the robot and nearby objects. When an obstacle is detected within a predefined distance, the Arduino processes the sensor data and controls the motors through a motor driver to change the robot's direction.

##  Components Used

* Arduino
* Ultrasonic Sensor
* Motor Driver
* DC Motors
* Robot Chassis
* Wheels
* Battery

##  Working

1. The ultrasonic sensor continuously measures the distance in front of the robot.
2. The Arduino receives the distance information.
3. If an obstacle is detected, the Arduino sends control signals to the motor driver.
4. The robot changes its direction to avoid the obstacle.
5. The robot continues moving forward after avoiding the obstacle.

##  Technologies Used

* Arduino
* Embedded C/C++
* Ultrasonic Sensing
* Motor Control

## Objective

To develop a simple autonomous robotic vehicle capable of detecting and avoiding obstacles without manual control.
